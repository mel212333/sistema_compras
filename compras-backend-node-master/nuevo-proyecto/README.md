# Nuevo Proyecto Full Stack

Proyecto base con:

- Backend: Node.js + Express + Sequelize
- Base de datos: PostgreSQL
- Frontend: React + Vite

## Levantar base de datos

```bash
docker compose up -d
```

## Backend

```bash
cd backend
npm install
npm run dev
```

API: http://localhost:3001

## Frontend

```bash
cd frontend
npm install
npm run dev
```

App: http://localhost:5173
